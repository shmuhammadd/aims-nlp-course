# Books folder

[Course home](../README.md) · [Research and model guide](../course/READINGS.md)

The course does not require this folder. Per the main README: "students do not need the bundled books directory to complete the course." Assigned readings are primary papers and public documentation, listed in [`course/READINGS.md`](../course/READINGS.md).

## Status of the existing PDFs

The four general-purpose NLP/LLM PDFs already in this folder, plus `ed3book_jan26-2.pdf`, are retained from a previous edition. One filename (`Hands-On Large Language Models ... (z-library.sk ...)`) indicates it was sourced from a piracy site. Do not add further PDFs obtained this way. Replace it with a legitimately obtained copy, or remove it, before distributing this repository.

## Multimodal books (not included)

Two books recommended for sessions 11–14 (vision-language, speech, video) are not included here because they are paid, copyrighted works. Access them through a library, institutional subscription, or purchase:

- **Vision Language Models** (Noyan, Marafioti, Farré, Zohar; O'Reilly, July 2026)
- **Large Vision-Language Models: Pre-training, Prompting, and Applications** (Springer, Advances in Computer Vision and Pattern Recognition series)

The free, open alternative is the primer [An Introduction to Vision-Language Modeling](https://arxiv.org/abs/2405.17247) (Bordes et al., 2024), already linked from `course/READINGS.md`.
